# 底盘开环标定参数

## 固定条件

| 项目 | 值 |
|------|----|
| 控制周期 | 10ms |
| 加减速参数 | ramp_ticks = 30 |
| 前后速度 | vy = +/-120 |
| 横移速度 | vx = +/-120 |
| 航向目标 | target_angle = 0 deg |
| 控制方式 | 速度 + 时间开环, IMU 仅用于航向修正 |
| 当前测试地面 | 待补充 |
| 当前电池状态 | 待补充 |

## 方向约定

| 参数 | 当前实车方向 | 备注 |
|------|--------------|------|
| vy > 0 | 前进 | 若代码中已对 vy_body 取反, 按此约定使用 |
| vy < 0 | 后退 | |
| vx > 0 | 左移 | 与早期注释中的“向右为正”相反 |
| vx < 0 | 右移 | |

## 实测记录

等效 tick 按以下公式计算:

```text
effective_ticks = hold_ticks + ramp_ticks
```

原因: 正弦加速段和正弦减速段合计约等效为一个 ramp_ticks 的满速时间。

| 方向 | 速度 | hold_ticks | ramp_ticks | effective_ticks | 实测距离(mm) | mm/tick | 备注 |
|------|------|------------|------------|-----------------|--------------|---------|------|
| 前进 | vy=120 | 100 | 30 | 130 | 820 | 6.31 | |
| 前进 | vy=120 | 150 | 30 | 180 | 1133 | 6.29 | |
| 左移 | vx=120 | 100 | 30 | 130 | 810 | 6.23 | vx 正数为左移 |
| 右移 | vx=-120 | 100 | 30 | 130 | 810 | 6.23 | vx 负数为右移 |

## 当前采用值

| 运动方向 | 速度 | ramp_ticks | 采用比例 | 换算公式 |
|----------|------|------------|----------|----------|
| 前进/后退 | vy=+/-120 | 30 | 6.30 mm/tick | hold_ticks = 目标距离(mm) / 6.30 - 30 |
| 左移/右移 | vx=+/-120 | 30 | 6.23 mm/tick | hold_ticks = 目标距离(mm) / 6.23 - 30 |

## 使用注意

1. 上表只适用于速度为 120, ramp_ticks 为 30, 控制周期为 10ms 的当前配置。
2. 若修改速度、ramp_ticks、控制周期、地面或负载, 需要重新标定。
3. 电量下降会影响开环距离, 当前建议在比赛前用相同电量状态复测一段 800mm 左右的标准动作。
4. 前后和横移比例不同是正常现象, 路线计算时应分开使用。
5. 当前 `car.actual_x/y` 不由开环函数维护, 路线不要混用旧的绝对坐标闭环接口。
